## About the project

This project recreates the classic Tic-Tac-Toe experience for two players:

- Players take turns placing `O` and `X` on a 3x3 board.
- Winning combinations are checked after every move.
- The game announces the winner or identifies a draw.
- Players can start a new game or reset the current board.

The game runs directly in the browser with no frameworks or build tools required.
